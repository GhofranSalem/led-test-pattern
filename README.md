# LED Screen Content

A browser tool that makes content for event LED screens at any resolution, including custom ones: abstract backgrounds as images and videos, plus test patterns. Everything runs in the browser, no server and no build step.

## الصفحات

| الصفحة | الملف | بتعمل إيه |
|---|---|---|
| **خلفيات Abstract** | `index.html` | صور PNG وفيديوهات MP4 بالرزلوشن بتاع الشاشة بالظبط |
| **صور اختبار** | `test-pattern.html` | Grid وكابينات مترقمة و Color bars وتدرجات، بالرزلوشن بتاع الشاشة |

الرزلوشن بيتنقل معاك لما تروح من صفحة للتانية.

## التشغيل

افتح `index.html` في **Chrome أو Edge**، أو ارفع الفولدر على أي استضافة static (GitHub Pages أو Cloudflare Pages أو Netlify).

لتشغيله محليًا بسيرفر:

```bash
python3 -m http.server 8000
```

## خلفيات Abstract

- **الستايلات (6):** Gradient Blobs، و Waves، و Flow Lines، و Bokeh، و Low Poly، و Smooth Gradient.
- **الألوان:** 8 باليتات جاهزة، وتقدر تعدل كل لون منهم بنفسك (أول لون هو الخلفية).
- **شكل جديد 🎲:** بيغيّر التوزيع بنفس الستايل والألوان.
- **الكثافة:** عدد العناصر في الصورة.
- **Grain خفيف:** بيقلل الـ banding (التدرجات اللي بتبان كخطوط) على شاشات LED.
- **الفيديو:**
  - MP4 بصيغة H.264.
  - المدة 10 أو 15 أو 30 أو 60 ثانية، والـ FPS ‏25 أو 30 أو 50 أو 60.
  - الفيديو **بيلف loop من غير قطع**: آخر فريم بيكمّل على أول فريم.
  - المحتوى بيترسم على رزلوشن الشاشة الحقيقي، فمفيش أي تكبير أو بهتان مهما كان المقاس عريض أو غريب.
- **لوجو الشركة:**
  - ترفع ملف SVG أو PNG، تختاره أو تسحبه على المكان المخصص.
  - تتحكم في الحجم (كنسبة من ارتفاع الشاشة)، والمكان (9 أماكن جاهزة، أو تسحب اللوجو بالماوس على المعاينة)، والبعد عن الحافة، والشفافية.
  - **تنبيه لو اللوجو صغير:** لو اللوجو PNG وهيتكبّر عن مقاسه الأصلي على الرزلوشن اللي اخترته، بيطلع تحذير فيه المقاس المطلوب.
  - SVG بيفضل حاد في أي مقاس.
  - اللوجو بيتحفظ في المتصفح للمرة الجاية.
- **رابط بالإعدادات:** كل الإعدادات بتتحفظ في عنوان الصفحة، فتقدر تبعت اللينك لحد يفتح نفس الشكل بالظبط.

### حدود الفيديو

- محتاج **Chrome أو Edge** على الكمبيوتر، لأنه بيستخدم WebCodecs.
- لو العرض أو الطول رقم فردي، الفيديو بيتزوّد بكسل أسود على الطرف، لأن H.264 محتاج أرقام زوجية.
- سرعة التحويل بتعتمد على الجهاز. المقاسات الكبيرة جدًا (زي 7680×1080 لمدة 30 ثانية) ممكن تاخد كام دقيقة.
- لو الجهاز مش قادر يعمل H.264 بمقاس معين، الموقع بيطلّع رسالة واضحة بدل ما يفشل من غير سبب.

## صور الاختبار

- **حساب بالكابينات:** حدود كل كابينة ورقمها مرسومين على الصورة.
- **الخلفيات:** Color bars، وتدرج رمادي، وتدرج RGB.
- **العناصر:** Grid بخطوط 1px، ودواير، و Crosshair، وإطار 1px.
- **ألوان كاملة:** R/G/B/W/Black بضغطة واحدة.
- **التصدير:** PNG من غير ضغط، وكل الخطوط على بكسلات صحيحة.

## هيكل الملفات

```
index.html           صفحة الخلفيات
abstract.js          واجهة صفحة الخلفيات
generators.js        رسم الستايلات (resolution-independent، loop-safe)
video.js             تصدير MP4 (WebCodecs + mp4-muxer)
logo.js              تحميل اللوجو ومكانه وتنبيه الجودة
test-pattern.html    صفحة صور الاختبار
app.js / pattern.js  واجهة ورسم صور الاختبار
save.js              حفظ الملفات (ومتوافق كمان مع صفحات claude.ai)
style.css            التنسيق المشترك
vendor/mp4-muxer.js  مكتبة mp4-muxer 5.2.1 (MIT)
```

## أفكار للمراحل الجاية

- تصدير بصيغة HAP لـ Resolume، عن طريق سيرفر FFmpeg.
- ستايلات أكتر، ونص (اسم الإيفنت) فوق الخلفية.

# LED Test Pattern

A browser tool that generates test images for event LED screens at any resolution, including custom ones. Everything runs in the browser, no server and no build step.

## التشغيل

افتح `index.html` في Chrome أو Edge، أو ارفع الفولدر على أي استضافة static (GitHub Pages أو Netlify أو Cloudflare Pages).

لتشغيله محليًا بسيرفر:

```bash
python3 -m http.server 8000
```

وبعدين افتح `http://localhost:8000`.

## المميزات

- **أي رزلوشن:** تكتب العرض والطول بالبكسل، أو تختار preset جاهز، أو تحفظ رزلوشن الشاشات اللي بتستخدموها كتير.
- **الحساب بالكابينات:** تكتب عدد الأعمدة والصفوف ومقاس الكابينة بالبكسل، والرزلوشن يتحسب لوحده. ممكن كمان ترسم حدود كل كابينة ورقمها (`C3 R2`).
- **الخلفيات:** أسود، أو لون تختاره، أو Color bars، أو تدرج رمادي (ناعم و 16 درجة)، أو تدرج R/G/B/W.
- **العناصر اللي تتحط على الصورة:**
  - Grid بخطوط 1px.
  - دواير للتأكد من الـ aspect ratio.
  - Crosshair وأقطار.
  - إطار 1px وأسهم في الأركان.
  - بيانات الرزلوشن واسم الإيفنت واسم الشاشة.
- **ألوان كاملة:** R/G/B/W/Black بضغطة واحدة، لاختبار الـ dead pixels وتساوي الألوان.
- **رابط مشاركة:** كل الإعدادات بتتحفظ في الرابط، فتقدر تبعته للأوبريتر يفتحه ويحمّل نفس الصورة.
- **التصدير PNG بس:** من غير أي ضغط، وكل الخطوط مرسومة على بكسلات صحيحة، فالخط اللي عرضه 1px بيطلع 1px بالظبط.

|---|---|
| أقصى طول لأي ضلع | 32767 px |
| أقصى مساحة | حوالي 268 ميجا بكسل (16384 × 16384) |
| Safari على iPhone/iPad | ممكن يفشل فوق 16.7 ميجا بكسل تقريبًا |

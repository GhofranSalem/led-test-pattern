Set it as the screensaver

Windows

  1. Install Lively Wallpaper (free, open source): github.com/rocksdanister/lively
  2. In Lively, add a wallpaper and paste the screensaver link.
  3. Open Lively's Settings → Screensaver and follow the steps.

Mac

  1. Install WebViewScreenSaver (free, open source): github.com/liquidx/webviewscreensaver
  2. Open System Settings → Screen Saver and choose WebViewScreenSaver.
  3. Open its Options and add the screensaver link.

Still image, no extra app

Download a PNG at your screen size (preset “This screen”), put it in a folder, and choose that folder in the built-in Photos screensaver on Windows or a photo screensaver on Mac.

The event name is part of the link. The logo is saved in this browser only, so screensaver apps won't show it.

The preview is scaled down. Files are made at full resolution.
